# 樽職人 木材種別スピリッツペアリングクイズ

アメリカンオーク・フレンチオーク・シェリー樽・ミズナラなど7種の樽材とウイスキー・ブランデー・ラムの風味相性を4択で答えるクイズアプリ。各樽材の風味プロフィールをレーダーバーチャートで視覚的に比較できる。

## 機能
- 7種の樽材データベース（アメリカンオーク・フレンチオーク・シェリー・ミズナラ・ポート・バーボン再利用・ラム）
- 3つのクイズモード（樽→風味、風味→樽、スピリッツ→樽）
- インタラクティブ風味チャート（バニラ・スパイス・フルーツ等7要素を5段階比較）
- SVG木目イラスト付き樽材解説
- 樽職人用語集（チャー・トースト・エンジェルズシェア等11語）
- ベストスコアのlocalStorage保存
